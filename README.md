# BuzzLock
### A Password Manager Thing! (i-change pa ni ahahah)
## 1. Overview

This project is a C# WIndows Forms Application using SQLite.
It follows the MVC architecture (Model-View-Controller) for cleaner code organization.

The system includes: 
- Secure Password Generation
- Secure Authentication
- Secure Vault Storage
*** 
## 2. Requirements
Before starting, make sure the following are installed:
- Visual Studio 2022
- .NET 8 SDK
- SQLite
- Git (for version control)
***
## 3. Getting Started
### Step 1. Clone the Repository
If the repository is on GitHub, open a terminal and run:
```
git clone https://github.com/<your-username>/BuzzLock.git
cd BuzzLock
```

### Step 2. Open in Visual Studio
1. Open **Visual Studio 2022**.
2. Select **File → Open → Project/Solution**.
3. Choose the folder you cloned ('BuzzLock').
4. Make sure the target framework is **.NET 8.0**.
